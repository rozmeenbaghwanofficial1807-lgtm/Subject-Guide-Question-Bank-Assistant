# Subject Guide & Question Bank Assistant AI Agent

## About the Project
The Subject Guide & Question Bank Assistant is an AI-based application designed to help students understand their syllabus, study notes, and previous question papers.

## Current Features
- Accepts a PDF file path from the user.
- Extracts readable text from PDF documents.
- Separates extracted content by page.
- Saves extracted text into a text file.
- Handles missing files and unsupported file formats.

## Technologies Used
- Python
- PyPDF
- Git and GitHub
- Visual Studio Code

## Setup Instructions

1. Clone or download this repository.
2. Create a Python virtual environment:
   `py -m venv .venv`
3. Activate the environment in Windows PowerShell:
   `.\.venv\Scripts\Activate.ps1`
4. Install dependencies:
   `python -m pip install -r requirements.txt`
5. Run the application:
   `python app.py`
6. Enter the full path of a PDF file when prompted.

## Planned Features
- Upload PDF files through a user interface.
